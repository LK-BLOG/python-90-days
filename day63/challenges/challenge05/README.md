# Challenge 05: Prompt 优化系统

## Boss 挑战

前 4 个挑战分别实现了 ReAct Agent、注入检测、上下文管理和 A/B 测试。现在构建一个完整的 **Prompt 自动优化系统**。

## 目标

实现 `PromptOptimizer` 类，支持：
- 自动 Prompt 优化：给定任务描述，自动生成和迭代优化 Prompt
- 注入防护：自动检测和防御 Prompt 注入攻击
- 上下文工程：动态构建最优上下文窗口
- 效果评估：量化 Prompt 质量（准确率/稳定性/成本）
- 版本对比：不同 Prompt 版本的 A/B 测试

## 验收标准
- [ ] 给定任务描述，自动生成候选 Prompt
- [ ] 注入检测器能识别 ≥ 5 种攻击模式
- [ ] 上下文构建器在 token 预算内最大化信息量
- [ ] 效果评估返回量化的质量分数
- [ ] A/B 测试自动对比不同 Prompt 版本
- [ ] 通过 test_day63.py 全部测试
