# Day 70 终极挑战：全模态 AI 助手

## 项目名称
**OmniBot —— 全模态 AI 助手**

## 目标
构建一个支持文本、图片、语音三种模态输入输出的统一 AI 助手，实现跨模态理解与生成的完整管道。

## 功能要求
1. **图像理解**：接收图片 URL/文件，调用 Vision 模型进行描述、OCR、场景分析、图表解读
2. **语音识别（STT）**：封装 Whisper API，支持 mp3/wav/m4a 格式，自动语言检测，返回带时间戳的转录文本
3. **语音合成（TTS）**：封装 OpenAI TTS API，支持多音色（alloy/echo/fable/onyx/nova/shimmer），语速可调
4. **多轮语音对话**：用户语音输入 → STT → LLM 生成回答 → TTS 播报，完整闭环
5. **图片问答**：用户上传图片 + 文字问题，模型基于图片内容回答
6. **文档 OCR**：支持从 PDF/图片中提取文字，保留排版结构
7. **模态路由器**：自动检测输入模态（文本/图片/音频），路由到对应的处理管道
8. **对话历史**：维护多模态对话上下文，支持跨模态追问（如"这张图里的那个人是谁"）
9. **Web API**：FastAPI 封装，提供 `/chat`、`/voice`、`/image`、`/ocr` 四个端点
10. **本地缓存**：TTS 音频和嵌入向量缓存到本地，避免重复调用

## 验收标准
- [ ] 图片描述准确，能识别图中主要物体和场景
- [ ] STT 转录准确率 ≥ 90%（普通话测试集）
- [ ] TTS 输出音频清晰自然，支持至少 3 种音色
- [ ] 语音对话端到端延迟 < 10 秒
- [ ] 模态路由器能正确区分三种输入类型
- [ ] Web API 四个端点均可用且有错误处理
- [ ] 多轮对话上下文保持正确
