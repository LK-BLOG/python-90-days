# Challenge 05: 多模态应用

## Boss 挑战

前 4 个挑战分别实现了图片描述器、语音转文字、简易语音助手和图文分析器。现在构建一个**完整的多模态 AI 应用**。

## 目标

实现 `MultimodalApp` 类，支持：
- 图片理解 + 分析（描述/OCR/问答）
- 语音处理（STT → LLM → TTS 全链路）
- 模态路由（自动识别输入类型）
- 多模态对话历史管理
- 统一 Web API 接口

## 验收标准
- [ ] 图片问答能基于图片内容回答
- [ ] 语音对话端到端流程完整
- [ ] 模态路由器能自动区分文本/图片/音频
- [ ] 多模态对话历史完整
- [ ] Web API 覆盖所有功能
- [ ] 通过 test_day70.py 全部测试
