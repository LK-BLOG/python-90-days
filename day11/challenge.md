# Day 11 挑战：模块系统

## 挑战概述
掌握Python模块系统，学会组织和管理代码。

## 核心挑战
1. **模块创建**：创建可复用的模块
2. **包结构**：设计合理的包结构
3. **导入机制**：掌握各种导入方式
4. **代码组织**：将项目拆分为多个模块

## 具体任务

### 挑战1：工具模块
创建一个工具模块：
- 字符串处理函数
- 文件操作函数
- 数据验证函数
- 使用__all__控制导出

### 挑战2：包结构设计
设计一个包结构：
- 创建__init__.py
- 设计模块划分
- 使用相对导入
- 避免循环导入

### 挑战3：模块化Todo系统
将Day 7的Todo系统模块化：
- 数据模型模块
- 存储模块
- 管理器模块
- CLI模块

## 输入/输出示例
```python
# 创建工具模块
from utils import string_utils, file_utils

# 使用模块
result = string_utils.format_text("hello world")
content = file_utils.read_file("test.txt")
```

## 限制条件
1. 每个模块职责单一
2. 使用相对导入
3. 避免循环导入
4. 代码必须有中文注释

## 验收标准
- [ ] 模块创建正确
- [ ] 包结构合理
- [ ] 导入方式正确
- [ ] 无循环导入
- [ ] 通过所有测试
