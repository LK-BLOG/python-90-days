# Day 11: 模块系统

## 🎯 今日目标
掌握Python模块系统，学会组织和管理代码。

## 📚 知识点
- import/from机制
- 模块搜索路径(sys.path)
- __name__=='__main__'
- __all__
- 循环导入问题
- 模块重载
- 包 vs 模块

## 🛠️ 实践项目
- 模块化Todo系统
- 命令调度器
- 插件系统
