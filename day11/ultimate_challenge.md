# Day 11 Boss挑战：插件式命令调度系统

## 挑战描述
实现一个插件式命令调度系统，支持动态导入模块、自动注册命令。

## 核心功能
1. **动态导入**：运行时导入模块
2. **自动注册**：自动发现和注册命令
3. **命令调度**：根据命令调用相应函数
4. **插件管理**：加载/卸载插件

## 具体任务

### 任务1：命令注册机制
实现命令注册：
- 装饰器注册
- 自动发现
- 命令验证
- 命令信息

### 任务2：动态导入系统
实现动态导入：
- 模块发现
- 动态加载
- 错误处理
- 热重载

### 任务3：命令调度器
实现命令调度：
- 命令解析
- 参数处理
- 执行命令
- 结果处理

### 任务4：插件管理
实现插件管理：
- 插件发现
- 插件加载
- 插件卸载
- 插件配置

## 输入/输出示例
```python
# 创建调度器
dispatcher = CommandDispatcher()

# 注册命令
@dispatcher.command("hello")
def hello(name="World"):
    return f"Hello, {name}!"

# 执行命令
result = dispatcher.execute("hello", name="Python")
print(result)  # Hello, Python!

# 动态加载插件
dispatcher.load_plugin("my_plugin")
```
