# Challenge 05: 完整文档助手

## Boss 挑战

前 4 个挑战分别实现了 RAG 查询器、对话管理器、引用溯源器和 API 封装器。现在构建一个**完整的文档问答助手**。

## 目标

实现 `DocAssistant` 类，支持：
- 文档导入 + 向量索引
- 多轮对话管理
- 查询改写 + 检索 + 重排序 + 生成
- 引用溯源（标注来源文档和片段）
- 流式输出
- WebSocket 实时对话
- 对话持久化
- 反馈收集

## 验收标准
- [ ] 多轮对话上下文保持 ≥ 10 轮
- [ ] 引用溯源标注准确
- [ ] 流式输出逐 token 推送
- [ ] 对话可持久化和恢复
- [ ] 反馈数据正确记录
- [ ] 完整的 RESTful API 接口定义
- [ ] 通过 test_day75.py 全部测试
