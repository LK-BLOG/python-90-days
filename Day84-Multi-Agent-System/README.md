今天你将学习如何构建和协调多Agent系统。

## 🔑 核心概念

### 多Agent协作模式

| 模式 | 描述 | 适用场景 |
|------|------|----------|
| 主从模式 | 一个主Agent协调多个从Agent | 明确分工的任务 |
| 对等模式 | Agent之间平等协作 | 开放式讨论 |
| 竞争模式 | 多个Agent竞争完成任务 | 需要多样方案 |
| 流水线模式 | Agent按顺序处理 | 流程化任务 |
