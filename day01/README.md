# Day 1: 函数参数

## 今日概览
函数是编程的核心构建块。今天我们深入研究函数参数的各种形态，掌握灵活定义和调用函数的能力。

## 学习目标
- 掌握位置参数、关键字参数、默认参数的区别和用法
- 理解参数传递的可变/不可变机制
- 学会使用 *args 和 **kwargs
- 掌握仅位置参数(/)和仅关键字参数(*)
- 学会参数解包
- 完成多格式报告生成器Boss挑战
