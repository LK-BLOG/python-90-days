# 挑战一：参数变形器

## 难度
★☆☆☆☆

## 目标
编写一个函数，接收任意位置参数和关键字参数，返回格式化的信息字符串。

## 背景
调试时快速查看传入函数的所有参数。

## 功能要求
实现 `describe_args(*args, **kwargs)`：
- 先列出位置参数的类型和值
- 再列出关键字参数的键、类型和值
- 格式：`"位置: int(1), str(hello) | 关键字: name(str)=张三, age(int)=25"`

## 示例
```python
describe_args(1, "hello", name="张三", age=25)
# "位置: int(1), str(hello) | 关键字: name(str)=张三, age(int)=25"

describe_args()
# ""
```

## 验收标准
1. ✅ 能处理空参数
2. ✅ 位置参数格式正确
3. ✅ 关键字参数格式正确
4. ✅ 类型信息正确
