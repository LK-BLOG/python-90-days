# Day 82: Memory 系统

## 🎯 学习目标

- 理解短期记忆（对话历史）
- 实现长期记忆（向量存储）
- 掌握工作记忆（当前任务状态）
- 学习记忆检索与遗忘
- 了解MemGPT基础

## 📋 前置知识

- Day 81: Context Engineering
- 向量数据库基础
- 嵌入模型

## ⏰ 预计时间：2小时

---

记忆是Agent的"长期知识"。没有记忆，Agent每次对话都是"失忆"状态。

今天你将构建一个多层记忆系统，让Agent能够积累和利用经验。

## 🔑 核心概念

### 三层记忆架构

`
┌─────────────────────────────────────────┐
│        短期记忆 (Short-term)             │
│        当前对话历史                      │
├─────────────────────────────────────────┤
│        工作记忆 (Working)                │
│        当前任务状态                      │
├─────────────────────────────────────────┤
│        长期记忆 (Long-term)              │
│        向量存储，持久化                  │
└─────────────────────────────────────────┘
`
