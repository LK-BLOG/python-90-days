# Day 16 Boss 挑战 — 向量/矩阵类

## 项目名称
VectorMath — 向量与矩阵运算库

## 目标
设计完整的向量/矩阵类，支持所有数学运算、切片、比较、可调用。

## 功能要求

### Vector 类
1. 创建: Vector(1, 2, 3) 或 Vector([1, 2, 3])
2. 算术: +, -, *, /, 取负, 绝对值
3. 点积, 叉积(3D), 模长
4. 比较: ==, <, >（按模长）
5. 切片: v[0:2]
6. 可调用: v(func) 对每个元素应用函数
7. 迭代: for x in v
8. 长度: len(v)
9. 格式化: "{v:.2f}"

### Matrix 类
10. 创建: Matrix([[1,2],[3,4]])
11. 加法, 标量乘法
12. 矩阵乘法 (@运算符)
13. 转置
14. 行列式(2x2)

### 验收标准
- Vector(1,2) + Vector(3,4) == Vector(4,6)
- Vector(1,2,3).dot(Vector(4,5,6)) == 32
- Vector(1,2).magnitude() ≈ 2.236
- v[0:2] 返回新 Vector
- v(lambda x: x*2) == Vector(2,4)
- Matrix([[1,2],[3,4]]) @ Matrix([[5,6],[7,8]]) 正确
