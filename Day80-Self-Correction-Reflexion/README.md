人会犯错，Agent也会。但好的Agent能**发现错误并自我纠正**。

今天你将学习如何让Agent具备反思和自我改进的能力。

## 🔑 核心概念

### Reflexion 循环

`
┌─────────────────────────────────────┐
│  执行 → 观察 → 反思 → 改进 → 再执行  │
│     ↑                       │        │
│     └───────────────────────┘        │
└─────────────────────────────────────┘
`

### 错误类型

| 类型 | 描述 | 处理方式 |
|------|------|----------|
| 工具错误 | 工具执行失败 | 重试/换工具 |
| 逻辑错误 | 推理错误 | 反思/重新推理 |
| 输入错误 | 参数错误 | 修正输入 |
| 超时错误 | 执行超时 | 重试/简化 |
