# Day 10 挑战：文件系统操作

## 挑战概述
掌握pathlib和os模块，实现文件系统操作。

## 核心挑战
1. **路径操作**：pathlib基础
2. **目录遍历**：glob和递归遍历
3. **文件管理**：复制、移动、删除
4. **系统信息**：环境变量、文件元数据

## 具体任务

### 挑战1：路径操作工具
实现路径操作工具：
- 路径拼接和解析
- 相对路径计算
- 路径规范化
- 跨平台兼容

### 挑战2：目录分析器
实现目录分析：
- 统计文件数量
- 计算目录大小
- 分析文件类型
- 生成目录树

### 挑战3：文件整理工具
实现文件整理：
- 按扩展名分类
- 按日期分类
- 查找重复文件
- 清理旧文件

## 输入/输出示例
```python
# 路径操作
path = Path("documents/report.txt")
print(f"父目录: {path.parent}")
print(f"扩展名: {path.suffix}")

# 目录分析
analyzer = DirectoryAnalyzer("/home/user")
print(analyzer.get_stats())
```
