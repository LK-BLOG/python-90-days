# Day 10 Boss挑战：智能文件管理器

## 挑战描述
实现一个智能文件管理器，按规则自动整理、去重、重命名、生成报告。

## 核心功能
1. **自动整理**：按规则分类文件
2. **文件去重**：查找和删除重复文件
3. **智能重命名**：按规则批量重命名
4. **报告生成**：生成详细的文件报告

## 具体任务

### 任务1：规则引擎
实现文件整理规则：
- 按扩展名分类
- 按日期分类
- 按大小分类
- 自定义规则

### 任务2：重复检测
实现重复文件检测：
- 按文件名查找
- 按大小查找
- 按内容查找
- 安全删除

### 任务3：批量重命名
实现批量重命名：
- 序号重命名
- 日期重命名
- 模式重命名
- 预览功能

### 任务4：报告系统
生成详细报告：
- 文件统计
- 操作日志
- 错误记录
- 可视化展示

## 输入/输出示例
```python
# 创建管理器
manager = SmartFileManager("/home/user")

# 整理文件
manager.organize_by_extension()

# 查找重复
duplicates = manager.find_duplicates()
print(f"找到 {len(duplicates)} 组重复文件")

# 生成报告
report = manager.generate_report()
print(report)
```
