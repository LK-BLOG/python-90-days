# Boss: Log Stream Processor

## Goal
Build a streaming log processor with constant memory.

## Requirements
1. StreamLogProcessor class
2. filter_by_level(level) - return filtered iterator
3. filter_by_keyword(keyword) - return filtered iterator
4. aggregate_by_level() - count each level
5. aggregate_by_hour() - count by hour
6. group_by_module() - group by module field
