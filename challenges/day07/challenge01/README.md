# 挑战1：基础Todo类

## 项目名称
基础Todo类实现

## 目标
创建一个功能完整的Todo类，包含输入验证、字典转换和友好的字符串表示。

## 背景
Todo是任务管理的基础单元。一个好的Todo类应该包含所有必要的信息，并提供方便的操作方法。

## 功能要求
1. **属性管理**：
   - id: 唯一标识符
   - title: 标题（必填，1-100字符）
   - description: 描述（可选）
   - priority: 优先级（高/中/低）
   - tags: 标签列表
   - completed: 完成状态
   - created_at: 创建时间
   - completed_at: 完成时间

2. **方法实现**：
   - `complete()`: 标记为已完成
   - `to_dict()`: 转换为字典
   - `from_dict()`: 从字典创建实例
   - `__str__()`: 友好的字符串表示

3. **输入验证**：
   - 标题不能为空
   - 标题长度限制
   - 优先级值验证

## 输入
Todo的各个属性值

## 输出
- Todo对象实例
- 字典表示
- 字符串表示

## 限制条件
1. 仅使用Python标准库
2. 必须有完整的异常处理
3. 代码必须有中文注释
4. 必须通过所有测试用例

## 示例
```python
# 创建Todo
todo = Todo("学习Python", "完成Day7项目", "高", ["学习", "编程"])
print(todo)  # 输出: [✗] 🔴 学习Python

# 转换为字典
todo_dict = todo.to_dict()
print(todo_dict)

# 从字典恢复
todo2 = Todo.from_dict(todo_dict)
print(todo2.title)  # 输出: 学习Python
```
