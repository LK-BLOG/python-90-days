# 挑战5：数据分析系统（Boss挑战）

## 项目名称
高级数据分析系统

## 目标
在基础Todo管理器上，添加强大的数据分析和可视化功能。

## 功能要求
1. **时间序列分析**：
   - 按日期统计添加/完成数量
   - 按周统计趋势
   - 按月汇总

2. **优先级分析**：
   - 各优先级完成率
   - 优先级变化趋势
   - 高优先级任务分析

3. **效率分析**：
   - 每日任务完成量
   - 平均完成时间
   - 工作时段分析

4. **报表生成**：
   - Markdown格式报表
   - 字符图表
   - 改进建议

## 输入/输出示例
```python
# 生成分析报表
analyzer = TodoAnalyzer(todos)
report = analyzer.generate_report()
print(report)

# 输出:
# 📊 Todo数据分析报表
# 生成时间: 2024-01-15 14:30:00
# 时间范围: 最近7天
# ...
```

## 限制条件
1. 仅使用标准库
2. 报表必须为Markdown格式
3. 统计必须准确
4. 代码必须有详细注释
