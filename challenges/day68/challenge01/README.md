# 挑战一：查询改写器

## 难度
★☆☆☆☆

## 项目名
QueryRewriter - 查询改写器

## 目标
实现一个查询改写器，能够扩展、简化和优化用户查询。

## 背景
用户查询往往不够精确，改写可以提高检索效果。本挑战让你实现基本的查询改写功能。

## 功能要求
1. **查询扩展**：添加同义词和相关词
2. **查询简化**：去除无关词汇
3. **查询分解**：将复杂查询拆分为子查询
4. **关键词提取**：提取查询中的关键词

## 输入
- 用户原始查询
- 同义词词典（可选）
- 改写策略参数

## 输出
- 改写后的查询列表
- 关键词列表

## 限制条件
- 纯Python实现
- 不依赖外部NLP库
- 支持中文查询

## 示例
`python
rewriter = QueryRewriter()
expanded = rewriter.expand("Python怎么学？")
# 返回：["Python 学习", "Python 教程", "Python 入门"]
keywords = rewriter.extract_keywords("如何快速学习Python编程？")
# 返回：["Python", "学习", "编程"]
`
