# 挑战二：文本预处理管道

## 难度
★★☆☆☆

## 项目名
TextPreprocessor - 文本预处理管道

## 目标
构建一个完整的文本预处理管道，支持清洗、分块和元数据提取。

## 背景
文本预处理是检索系统的基础。本挑战让你实现从原始文本到可索引数据的完整流程。

## 功能要求
1. **文本清洗**：去除特殊字符、标准化空白
2. **智能分块**：支持固定大小和语义分块
3. **元数据提取**：提取标题、日期、关键词等
4. **管道配置**：支持自定义预处理流程

## 输入
- 原始文本
- 分块参数（大小、重叠等）
- 清洗规则

## 输出
- 清洗后的文本块列表
- 每个文本块的元数据

## 限制条件
- 纯Python实现
- 支持中文文本处理
- 分块结果需要保持语义完整性

## 示例
`python
preprocessor = TextPreprocessor()
chunks = preprocessor.process("长文本内容...", chunk_size=200, overlap=20)
# 返回 [{'text': 'chunk1', 'metadata': {...}}, ...]
`

## 验收标准
- [ ] 文本清洗功能正常
- [ ] 智能分块算法正确
- [ ] 元数据提取完整
- [ ] 管道配置灵活
- [ ] 代码有中文注释
