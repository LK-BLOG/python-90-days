# 挑战一：嵌入向量生成器

## 难度
★☆☆☆☆

## 项目名
EmbedGenerator - 嵌入向量生成器

## 目标
实现一个文本嵌入向量生成器，支持不同的嵌入策略。

## 背景
嵌入向量是将文本转换为数值表示的关键步骤。本挑战让你理解嵌入的基本原理。

## 功能要求
1. **基础嵌入**：实现基于字符的简单嵌入
2. **词袋嵌入**：实现词袋模型的嵌入
3. **TF-IDF嵌入**：实现TF-IDF加权嵌入
4. **维度控制**：支持指定嵌入向量维度

## 输入
- 文本字符串
- 嵌入维度参数
- 词典（可选）

## 输出
- 归一化的嵌入向量（numpy数组）

## 限制条件
- 纯Python实现，可使用numpy
- 不使用预训练模型
- 输出向量需要归一化

## 示例
`python
gen = EmbedGenerator(dim=8)
vec1 = gen.char_embedding("Python编程")
vec2 = gen.tfidf_embedding("Python编程", vocab=["Python", "编程", "语言"])
sim = gen.cosine_similarity(vec1, vec2)
`
