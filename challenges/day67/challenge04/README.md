# 挑战四：混合搜索引擎

## 难度
★★★★☆

## 项目名
HybridSearch - 混合搜索引擎

## 目标
实现一个结合向量搜索和关键词搜索的混合搜索引擎。

## 背景
纯语义搜索有时会漏掉关键词匹配，纯关键词搜索又缺乏语义理解。混合搜索取长补短。

## 功能要求
1. **向量搜索**：基于语义相似度的搜索
2. **关键词搜索**：基于BM25算法的搜索
3. **结果融合**：加权组合两种搜索结果
4. **动态权重**：根据查询特点自动调整权重

## 输入
- 文档集合
- 查询语句
- 搜索权重参数

## 输出
- 混合搜索结果（按融合分数排序）
- 各子搜索的独立结果

## 限制条件
- 纯Python实现，可使用numpy
- 实现简化版BM25
- 支持权重参数调整

## 示例
`python
searcher = HybridSearch(documents)
results = searcher.search("Python 机器学习", weights={"vector": 0.7, "keyword": 0.3})
# 返回融合后的搜索结果
`
