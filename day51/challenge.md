# Day 51 挑战任务

## Challenge 1: 自定义中间件
**目标：** 实现3个自定义中间件

**要求：**
1. 请求日志中间件（记录method/path/status/duration）
2. 请求ID中间件（生成和传递X-Request-ID）
3. 速率限制中间件（限制每IP每分钟请求数）
4. 错误处理中间件（统一错误格式）

**验收：** 所有中间件正常工作
**难度：** ⭐⭐

## Challenge 2: Celery集成
**目标：** 为博客API添加后台任务

**要求：**
1. 配置Celery + Redis
2. 邮件通知任务
3. 报告生成任务
4. 任务链（提取→转换→加载）
5. 任务状态查询API

**验收：** 任务异步执行，能查状态
**难度：** ⭐⭐⭐

## Challenge 3: 缓存层 + 搜索
**目标：** 为API添加缓存和搜索

**要求：**
1. 文章列表缓存（60秒TTL）
2. 文章详情缓存（300秒TTL）
3. 缓存失效（创建/更新/删除时）
4. 简单搜索（标题/内容模糊匹配）
5. 搜索结果缓存

**验收：** 缓存命中时响应<5ms
**难度：** ⭐⭐⭐
