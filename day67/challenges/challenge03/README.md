# 挑战三：嵌入质量评估器

## 难度
★★★☆☆

## 项目名
EmbedEvaluator - 嵌入质量评估器

## 目标
实现嵌入质量评估工具，能够测试嵌入模型的语义表达能力。

## 背景
嵌入质量直接影响检索效果。本挑战让你学会如何评估和比较不同的嵌入策略。

## 功能要求
1. **语义相似度测试**：测试同义句是否距离近
2. **语义差异测试**：测试反义句是否距离远
3. **聚类评估**：测试嵌入是否能有效聚类
4. **可视化**：生成嵌入空间的2D可视化

## 输入
- 测试文本对（同义句、反义句）
- 嵌入函数
- 评估指标参数

## 输出
- 评估报告（相似度分数、准确率等）
- 2D可视化图（可选）

## 限制条件
- 纯Python实现，可使用numpy
- 不依赖外部评估库
- 支持自定义嵌入函数

## 示例
`python
evaluator = EmbedEvaluator()
test_pairs = [
    ("我喜欢Python", "我爱Python", True),   # 同义
    ("我喜欢Python", "我讨厌Python", False), # 反义
]
report = evaluator.evaluate(embedding_func, test_pairs)
print(f"准确率: {report['accuracy']:.2%}")
`
