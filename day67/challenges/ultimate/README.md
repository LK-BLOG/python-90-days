# Boss挑战：智能文本检索系统

## 难度
★★★★★

## 项目名
SmartTextRetriever - 智能文本检索系统

## 目标
构建一个支持多种嵌入模型、混合搜索和质量评估的智能文本检索系统。

## 背景
在实际应用中，文本检索需要考虑多种因素：嵌入模型选择、文本预处理、搜索策略等。本挑战让你综合运用所学知识构建完整系统。

## 功能要求
1. **多模型支持**：支持不同嵌入模型的切换和比较
2. **智能预处理**：自动清洗、分块、提取元数据
3. **混合搜索**：结合语义搜索和关键词搜索
4. **质量评估**：自动评估检索质量
5. **结果优化**：重排序、去重、相关度过滤

## 输入
- 文档集合（支持txt/md格式）
- 查询语句
- 搜索参数（模型选择、搜索策略、top_k等）

## 输出
- 按相关性排序的文档片段
- 检索质量评估报告
- 搜索统计信息

## 限制条件
- 纯Python实现，可使用numpy
- 支持自定义嵌入函数
- 支持中文文档

## 示例
`python
system = SmartTextRetriever()
system.load_documents(["doc1.txt", "doc2.md"])
results = system.search("机器学习入门", model="mini-lm", strategy="hybrid")
report = system.evaluate_quality(test_queries)
`
