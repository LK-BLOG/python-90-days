# Day 3：位置参数、关键字参数与默认参数

## 今天要做出的东西

一个**成绩单设置生成器**。你会让函数支持：

- 按顺序传参数；
- 写出参数名传参数；
- 省略参数使用默认值；
- 避免可变默认参数造成的数据污染。

## 前置

先完成 Day 2 的列表与函数拆分。

## 学习顺序

1. 运行 `examples/` 中的函数参数示例；
2. 阅读 `lesson.md`；
3. 完成 `starter/challenge01.py` 到 `challenge05.py`；
4. 完成 `starter/ultimate.py`；
5. 每个函数增加两个自己的测试；
6. 最终版本放进 `code/`。
