# Day 78 挑战：开发5个不同类型的工具

## 挑战描述

开发5个实用工具，覆盖Agent最常见的操作场景。

## 任务要求

### 工具1：文件操作工具
- 支持文件读写
- 支持目录列表
- 路径安全验证

### 工具2：Shell执行工具
- 支持常用命令
- 命令安全检查
- 超时控制

### 工具3：代码执行工具
- 安全沙箱
- 输出捕获
- 错误处理

### 工具4：HTTP请求工具
- 支持GET/POST
- 请求头设置
- 响应解析

### 工具5：JSON处理工具
- JSON解析
- JSON格式化
- JSON查询（JSONPath）

## 验收标准

- [ ] 5个工具都能正常工作
- [ ] 每个工具有安全检查
- [ ] 完整的测试覆盖
- [ ] 清晰的使用文档
