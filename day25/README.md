# Day 25: Debug + 测试

## 📋 学习目标

完成今天的学习后，你将能够：
- 使用二分法和 print 快速定位 Bug
- 使用 logging 模块记录调试信息
- 使用 pdb 进行交互式调试
- 编写 assert 断言验证逻辑
- 使用 unittest 编写完整测试
- 使用 pytest 高效测试
- 理解 TDD 测试驱动开发
- 达到 80%+ 测试覆盖率

## 📚 学习内容

| 模块 | 内容 |
|------|------|
| Debug 思维 | 二分法、print 调试、logging 模块 |
| pdb 调试器 | 断点、单步、变量查看、调用栈 |
| assert 断言 | 用法、最佳实践、与异常的区别 |
| unittest 深入 | setUp/tearDown、Mock/patch、测试套件 |
| pytest 基础 | fixture、conmark、parametrize、插件 |
| 测试覆盖率 | coverage.py、报告生成、覆盖率目标 |
| TDD 基础 | 红-绿-重构 循环 |
