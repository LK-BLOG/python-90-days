# Challenge 04: 测试生成器

## 项目名称：TestGen

## 目标
编写一个自动生成测试用例的工具。

## 功能要求

### 1. 函数分析
- 解析函数签名
- 提取参数类型
- 识别默认值

### 2. 测试生成
- 生成边界测试
- 生成类型测试
- 生成异常测试

### 3. 输出格式
- unittest 格式
- unittest 格式
- 包含 docstring

### 4. 智能推断
- 推断参数含义
- 生成有意义的测试数据
- 处理复杂类型

## 验收标准
- [ ] 能解析函数签名
- [ ] 能生成 unittest 测试
- [ ] 测试用例合理
- [ ] 覆盖边界情况
