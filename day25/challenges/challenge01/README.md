# Challenge 01: Debug 工具箱

## 项目名称：DebugKit

## 目标
编写一个 Debug 工具箱，提供常用的调试工具。

## 功能要求

### 1. 二分法查找器
- 在数据中定位问题
- 支持自定义条件函数
- 返回问题位置和值

### 2. 执行时间测量器
- 装饰器形式
- 支持同步/异步函数
- 输出格式化时间

### 3. 内存分析器
- 测量函数内存使用
- 装饰器形式
- 输出内存增长

### 4. 调用栈打印器
- 显示完整调用链
- 支持过滤/限制深度
- 格式化输出

## 验收标准
- [ ] 所有工具可正常使用
- [ ] 支持装饰器形式
- [ ] 输出清晰可读
- [ ] 有完整文档字符串
