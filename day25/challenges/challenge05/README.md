# Challenge 05: 覆盖率分析器

## 项目名称：CoverageInsight

## 目标
编写一个覆盖率分析和报告工具。

## 功能要求

### 1. 数据解析
- 解析 coverage.xml
- 提取覆盖率数据
- 支持多种格式

### 2. 报告生成
- Markdown 报告
- 统计信息
- 未覆盖代码标记

### 3. 质量评分
- 计算综合评分
- 按模块统计
- 趋势分析

### 4. 可视化
- 生成覆盖率图表
- 对比报告
- 历史趋势

## 验收标准
- [ ] 能解析 coverage 数据
- [ ] 生成可读的报告
- [ ] 计算质量评分
- [ ] 支持对比分析
