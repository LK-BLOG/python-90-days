# Challenge 02: 日志系统

## 项目名称：LogCraft

## 目标
编写一个可配置的日志系统。

## 功能要求

### 1. 多输出目标
- 控制台输出
- 文件输出
- 支持同时输出到多个目标

### 2. 日志轮转
- 按大小轮转
- 按时间轮转
- 保留历史文件

### 3. 结构化日志
- JSON 格式输出
- 自定义字段
- 支持上下文信息

### 4. 性能优化
- 异步写入
- 日志过滤
- 批量写入

## 验收标准
- [ ] 支持多种输出目标
- [ ] 支持日志轮转
- [ ] 支持 JSON 格式
- [ ] 性能开销小
