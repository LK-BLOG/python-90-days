# Challenge 03: Mock 模拟器

## 项目名称：MockMaster

## 目标
编写一个简易的 Mock 框架。

## 功能要求

### 1. 基础 Mock
- 自动记录调用
- 配置返回值
- 支持属性访问

### 2. 参数验证
- 检查调用次数
- 验证调用参数
- 支持参数匹配器

### 3. 调用历史
- 记录所有调用
- 支持调用查询
- 生成调用报告

### 4. 高级功能
- Side effects（副作用）
- 调用顺序验证
- 嵌套 Mock

## 验收标准
- [ ] 能自动记录调用
- [ ] 能验证参数
- [ ] 能配置返回值
- [ ] 使用简单直观
