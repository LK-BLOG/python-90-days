今天你将学习如何评估Agent的表现，并建立完整的可观测性系统。

## 🔑 核心概念

### 可观测性三支柱

`
┌─────────────────────────────────────────┐
│              Logs                       │
│              日志                       │
├─────────────────────────────────────────┤
│              Metrics                    │
│              指标                       │
├─────────────────────────────────────────┤
│              Traces                     │
│              追踪                       │
└─────────────────────────────────────────┘
`

### 评估维度

| 维度 | 指标 |
|------|------|
| 准确性 | 正确率、相关性 |
| 效率 | 响应时间、Token使用 |
| 成本 | API调用费用 |
| 用户体验 | 满意度、任务完成率 |
