# Challenge 05: 代码质量检查器

## 项目名称：QualityGate

## 目标
编写一个代码质量检查工具，分析 Python 项目并生成报告。

## 功能要求

### 1. 代码统计
- 文件数量
- 代码行数（排除空行和注释）
- 注释行数
- 空行数
- 平均函数长度

### 2. 代码质量检查
- 未使用的 import
- 缺少 docstring 的函数/类
- 过长的函数（超过阈值）
- 过多的参数
- 复杂度过高（分支太多）

### 3. 项目健康度
- 测试覆盖率（如果有）
- 代码重复检测（简单实现）
- 依赖数量统计

### 4. 报告生成
- Markdown 格式报告
- 建议修复方案
- 严重程度分级（error/warning/info）

## 输入
- 项目根目录路径
- 配置选项（阈值、排除目录等）

## 输出
- Markdown 格式报告
- JSON 格式数据（可选）

## 限制
- 纯 Python 实现
- 不能依赖外部 lint 工具
- 支持 Python 3.9+

## 验收标准
- [ ] 能正确统计代码行数
- [ ] 能检测未使用的 import
- [ ] 能检测缺少的 docstring
- [ ] 能检测过长的函数
- [ ] 生成可读的 Markdown 报告

## 可选扩展
- 支持自定义规则
- 支持 HTML 报告
- 支持对比历史报告
- 集成到 CI/CD
- 支持配置文件
