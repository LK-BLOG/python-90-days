# Day 31: Git & 项目结构

## 🏗️ Phase 2 开篇：从脚本到工程

恭喜进入 Phase 2！今天开始，你不再是写脚本的人，你要学会像**工程师**一样管理项目。

## 🎯 学习目标

- Git 工作流：add/commit/branch/merge/rebase
- Commit message 规范（Conventional Commits）
- .gitignore 编写
- Python 项目结构（src layout vs flat layout）
- pyproject.toml 配置
- 虚拟环境管理（venv/virtualenv/pipenv）
- 依赖管理（requirements.txt/poetry/uv）

## 📚 学习路径
