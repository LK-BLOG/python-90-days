# Day 73 终极挑战：RAG 评估方案

## 项目名称
**RAGEval —— RAG 系统自动化评估平台**

## 目标
构建一个全面的 RAG 系统评估平台，涵盖检索质量、生成质量、端到端性能的自动化评估，支持持续集成和数据漂移检测。

## 功能要求
1. **评估指标引擎**：
   - 检索指标：Recall@K、MRR、NDCG、Hit Rate
   - 生成指标：BLEU、ROUGE-L、METEOR、BERTScore
   - RAG 专用指标：Faithfulness（忠实度）、Answer Relevancy（答案相关性）、Context Relevancy（上下文相关性）、Context Recall（上下文召回率）
2. **测试用例管理**：
   - 支持导入 golden dataset（标准问答对）
   - 支持按难度/类别/领域标签组织测试集
   - 版本控制 + 回归测试
3. **自动评估管道**：
   - 一键运行：输入 RAG 系统 + 测试集 → 输出完整评估报告
   - 并行评估：多组参数/模型同时评估
   - LLM-as-Judge：使用强模型评估弱模型的输出质量
4. **对比评估（A/B）**：
   - 支持两个 RAG 配置的 head-to-head 对比
   - 统计显著性检验（paired t-test / bootstrap）
   - 输出胜率/平率/负率
5. **评估报告生成器**：
   - 可视化：雷达图（多维度得分）、趋势图（版本间对比）、热力图（类别×指标）
   - 报告导出为 HTML + JSON
   - 自动生成改进建议
6. **数据漂移检测**：
   - 监控查询分布变化（embedding 空间的 KL 散度）
   - 监控检索结果质量衰减
   - 漂移告警 + 建议重新训练/更新索引
7. **CI/CD 集成**：
   - 支持作为 pytest 插件运行
   - 阈值门控：评估分数低于阈值时阻断部署
   - GitHub Actions / GitLab CI 示例配置
8. **基准测试套件**：
   - 内置 NQ、HotpotQA、TriviaQA 子集作为标准 benchmark
   - 公开排行榜格式（可选）

## 验收标准
- [ ] 评估引擎覆盖 ≥ 6 种核心指标
- [ ] 一键评估管道端到端运行 < 5 分钟（100 条测试）
- [ ] A/B 对比能输出统计显著性 p-value
- [ ] 评估报告包含可视化图表
- [ ] 数据漂移检测在模拟漂移场景下触发告警
- [ ] 可作为 pytest 插件运行并支持阈值门控
