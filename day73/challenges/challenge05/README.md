# Challenge 05: RAG 评估方案

## Boss 挑战

前 4 个挑战分别实现了评估指标计算器、测试用例管理器、自动评估器和评估报告生成器。现在构建一个**完整的 RAG 评估方案**。

## 目标

实现 `RAGEvalSuite` 类，支持：
- 多维度评估指标（检索质量 + 生成质量 + 端到端）
- 标准测试集管理
- 自动化评估管道
- 对比评估（A/B 测试）
- 可视化报告生成
- CI/CD 集成（pytest 插件）
- 数据漂移检测

## 验收标准
- [ ] 评估指标覆盖 ≥ 8 种
- [ ] 自动评估管道一键运行
- [ ] A/B 对比支持统计显著性检验
- [ ] 报告包含可视化图表（ASCII 版）
- [ ] 数据漂移检测能触发告警
- [ ] 可作为 pytest fixture 使用
- [ ] 通过 test_day73.py 全部测试
