# Day 8: 文件 I/O

## 🎯 今日目标
掌握Python文件操作，学会读写各种格式的文件，处理编码问题。

## 📚 知识点
- 文件打开模式（r/w/a/rb/wb）
- 文件读取方法（read/readline/readlines）
- 文件写入方法（write/writelines）
- with语句上下文管理
- 编码处理（utf-8/gbk）
- 大文件处理技巧
- 临时文件使用
- CSV文件基础

## 🛠️ 实践项目
- 日志文件分析器
- 配置文件管理器
- 数据导入导出工具
