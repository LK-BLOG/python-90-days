# 挑战1：日志分析器

## 项目名称
日志文件分析器

## 目标
实现一个日志文件分析工具，能够读取、解析和分析日志文件。

## 功能要求
1. **日志解析**：
   - 支持多种日志格式
   - 解析时间戳
   - 提取日志级别
   - 提取消息内容

2. **统计分析**：
   - 按级别统计
   - 按时间统计
   - 错误率计算

3. **搜索功能**：
   - 关键词搜索
   - 时间范围搜索
   - 级别过滤

## 输入/输出示例
```python
# 分析日志文件
analyzer = LogAnalyzer("app.log")
analyzer.parse()
print(analyzer.get_statistics())

# 搜索错误日志
errors = analyzer.search(level="ERROR")
print(f"找到 {len(errors)} 条错误日志")
```

## 限制条件
1. 仅使用标准库
2. 支持大文件处理
3. 代码必须有中文注释
