# Day 72 终极挑战：AI 安全过滤系统

## 项目名称
**AIShield —— 多层 AI 安全防护系统**

## 目标
构建一个多层防御的 AI 安全系统，集成输入过滤、输出审核、幻觉检测、提示注入防御和人类审核回路，全方位保障 AI 应用的安全性。

## 功能要求
1. **输入过滤层**：
   - 关键词黑名单 + 正则匹配（暴力/色情/政治敏感）
   - Prompt 注入检测（识别 roleplay/jailbreak/DAN 等攻击模式）
   - 输入长度和频率异常检测
2. **输出审核层**：
   - 调用 OpenAI Moderation API 进行内容分类
   - 自定义规则引擎（可配置的关键词 + 语义规则）
   - 机密信息脱敏（身份证号/手机号/邮箱自动打码）
3. **幻觉检测器**：
   - 要求模型引用来源，交叉验证引用的真实性
   - 置信度评分：对回答中的事实性声明逐条打分
   - 自相矛盾检测：检查回答内部逻辑一致性
4. **提示注入防御**：
   - 指令层级隔离（system prompt vs user input 严格分离）
   - 输入消毒（去除隐藏指令、特殊 Unicode 字符）
   - 沙箱模式：高风险输入在隔离环境中处理
5. **可解释性工具**：
   - 记录完整的决策链路（为什么拒绝/通过/标记）
   - Attention 权重可视化（简化版）
   - 生成安全审计报告
6. **人类审核回路**：
   - 低置信度结果自动提交人工审核队列
   - 审核工作流：待审 → 审核中 → 通过/拒绝/修改
   - 审核结果反馈到过滤规则（持续优化）
7. **安全仪表盘**：实时统计拦截次数、拦截类型分布、误报率
8. **规则热更新**：支持运行时加载/更新过滤规则，无需重启
9. **审计日志**：所有请求的输入/输出/决策记录，支持按时间/IP/关键词查询
10. **性能指标**：过滤延迟 < 50ms（不含外部 API 调用）

## 验收标准
- [ ] 能检测并拦截至少 10 种已知的 Prompt 注入模式
- [ ] 输出审核覆盖色情/暴力/自残/仇恨等类别
- [ ] 幻觉检测器能发现虚构的引用来源
- [ ] 机密信息自动脱敏准确率 ≥ 95%
- [ ] 人类审核工作流完整可用
- [ ] 过滤延迟 P99 < 50ms
- [ ] 安全审计日志完整可追溯
