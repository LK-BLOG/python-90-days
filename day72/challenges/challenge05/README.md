# Challenge 05: 安全过滤系统

## Boss 挑战

前 4 个挑战分别实现了内容过滤器、幻觉检测器、安全审核管道和可解释性工具。现在构建一个**完整的 AI 安全过滤系统**。

## 目标

实现 `SafetyFilterSystem` 类，支持：
- 多层过滤管道（输入过滤 → 模型调用 → 输出审核）
- Prompt 注入检测与防御
- 内容审核（暴力/色情/仇恨/自残）
- 幻觉检测（交叉验证 + 置信度评分）
- 机密信息脱敏
- 人类审核回路
- 审计日志

## 验收标准
- [ ] 能检测 ≥ 8 种注入攻击模式
- [ ] 输出审核覆盖 5 类有害内容
- [ ] 幻觉检测准确率 ≥ 70%
- [ ] 机密信息自动脱敏
- [ ] 低置信度结果进入人工审核队列
- [ ] 完整的审计日志可追溯
- [ ] 通过 test_day72.py 全部测试
