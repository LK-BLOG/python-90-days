## 📖 核心原则速查
- **S** — 单一职责：一个类只干一件事
- **O** — 开闭原则：对扩展开放，对修改关闭
- **L** — 里氏替换：子类能无缝替换父类
- **I** — 接口隔离：不要强迫实现不需要的接口
- **D** — 依赖倒置：依赖抽象而非具体实现
