# Day 12 挑战：包开发

## 挑战概述
掌握Python包开发，学会创建和发布自己的包。

## 核心挑战
1. **包结构设计**：创建标准的包结构
2. **模块组织**：合理组织模块
3. **依赖管理**：管理包依赖
4. **包发布准备**：准备发布到PyPI

## 具体任务

### 挑战1：创建工具包
创建一个工具包：
- 设计包结构
- 实现工具模块
- 添加__init__.py
- 编写文档

### 挑战2：依赖管理
管理包依赖：
- 创建requirements.txt
- 配置pyproject.toml
- 处理可选依赖
- 版本控制

### 挑战3：包测试
为包添加测试：
- 创建测试目录
- 编写单元测试
- 配置测试环境
- 生成测试报告

## 输入/输出示例
```python
# 创建包
from my_toolkit import string_utils, file_utils

# 使用包
result = string_utils.format_text("hello world")
content = file_utils.read_file("test.txt")
```

## 限制条件
1. 遵循包结构最佳实践
2. 使用相对导入
3. 添加完整文档
4. 代码必须有中文注释

## 验收标准
- [ ] 包结构正确
- [ ] 模块功能完整
- [ ] 依赖管理正确
- [ ] 文档完整
- [ ] 通过所有测试
