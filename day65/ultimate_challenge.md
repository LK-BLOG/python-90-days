# Day 65 终极挑战：生产级 RAG 系统

## 项目名称
**MiniRAG —— 轻量级检索增强生成系统**

## 目标
从零构建一个完整的 RAG 系统，涵盖文档解析、分块、嵌入、向量存储、检索、重排序和生成全流程，具备生产级的健壮性和可观测性。

## 功能要求
1. **文档加载器**：支持 PDF、Markdown、纯文本三种格式，自动提取文本内容
2. **智能分块器**：实现段落感知的滑动窗口分块，支持 chunk_size 和 overlap 配置，保留元数据（文件名、页码、章节标题）
3. **向量嵌入**：封装 OpenAI Embedding API，支持批量嵌入和本地缓存（避免重复调用）
4. **向量存储**：基于 NumPy 实现简易向量数据库，支持 add / search / delete / save / load
5. **检索管道**：Query → 查询改写（HyDE 可选）→ 向量检索 → 重排序（Cross-Encoder 或 MMR）→ Top-K 截断
6. **生成模块**：将检索到的上下文 + 用户问题拼接为 Prompt，调用 LLM 生成答案
7. **引用溯源**：答案中标注每段引用的来源文档和页码
8. **评估指标**：实现 Faithfulness（忠实度）和 Relevancy（相关性）的自动化评分
9. **CLI 入口**：支持 `ingest`（导入文档）、`query`（提问）、`evaluate`（跑评估集）三个子命令
10. **日志与监控**：记录每次查询的检索耗时、命中 chunk 数、token 用量

## 验收标准
- [ ] 能导入 5+ 篇文档并成功建立向量索引
- [ ] 查询返回的答案准确引用了源文档内容
- [ ] 检索结果支持按相关性排序和过滤
- [ ] 评估跑分 ≥ 0.7（忠实度 + 相关性均值）
- [ ] CLI 三个子命令均可正常运行
- [ ] 单元测试覆盖率 ≥ 80%
