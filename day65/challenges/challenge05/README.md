# Challenge 05: QA 系统

## Boss 挑战

前 4 个挑战分别实现了文档分块器、向量存储、嵌入生成器和 RAG 管道。现在构建一个完整的 **QA 问答系统**。

## 目标

实现 `QASystem` 类，支持：
- 文档导入与索引构建
- 语义检索 + 上下文拼接
- LLM 生成答案（带引用溯源）
- 多轮追问（上下文感知）
- 答案质量评估（相关性 + 忠实度）

## 验收标准
- [ ] 导入 ≥ 3 篇文档并建立索引
- [ ] 查询返回带引用的答案
- [ ] 支持基于检索结果的追问
- [ ] 答案质量评估分数可计算
- [ ] 通过 test_day65.py 全部测试
