- 学习动态上下文注入

- 理解上下文预算控制

## 📋 前置知识

- Day 76-80: Agent基础
- Token化基础
- 提示工程

## ⏰ 预计时间：2小时

---

上下文是Agent的"工作记忆"。管理不好上下文，Agent就会"失忆"或"混乱"。

今天你将学习如何高效管理Agent的上下文，让它在有限的窗口中完成复杂任务。

## 🔑 核心概念

### 上下文窗口的组成

`
┌─────────────────────────────────────────┐
│           System Prompt                 │
│           (系统提示)                     │
├─────────────────────────────────────────┤
│           Memory                         │
│           (记忆)                         │
├─────────────────────────────────────────┤
│           Conversation History          │
│           (对话历史)                     │
├─────────────────────────────────────────┤
│           Current Context               │
│           (当前上下文)                   │
├─────────────────────────────────────────┤
│           Response Space                │
│           (响应空间)                     │
└─────────────────────────────────────────┘
`
