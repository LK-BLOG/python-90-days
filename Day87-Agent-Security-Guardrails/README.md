Agent能访问工具、执行代码、甚至转账。**没有安全护栏的Agent是危险的**。

今天你将学习如何为Agent添加安全防护。

## 🔑 核心概念

### 安全防护层次

`
┌─────────────────────────────────────────┐
│           输入验证                       │
│     (Prompt Injection防护)              │
├─────────────────────────────────────────┤
│           输出检查                       │
│     (敏感信息过滤)                       │
├─────────────────────────────────────────┤
│           权限控制                       │
│     (工具调用权限)                       │
├─────────────────────────────────────────┤
│           沙箱执行                       │
│     (代码/命令隔离)                      │
└─────────────────────────────────────────┘
`
