# Day 76 终极挑战：Mini ReAct Engine

## 任务
从零实现一个最小化的 ReAct 引擎，包含完整的感知-思考-行动循环。

## 功能要求
1. **Agent 核心循环**：实现 eact_step() 和 eact_loop()
2. **工具系统**：支持注册、描述生成、调用
3. **Prompt 构建**：动态构建包含工具描述和历史的 prompt
4. **输出解析**：解析 LLM 输出为结构化的 Thought/Action
5. **退出条件**：支持 finish action 和 max_steps 退出
6. **追踪系统**：记录完整执行轨迹

## 测试用例
- 查询 "北京到上海的直线距离是多少公里？如果速度是350km/h，需要多少小时？"
  - 应该调用 search + calculator
- 查询 "1+1等于几"
  - 应该直接用 calculator 返回结果
