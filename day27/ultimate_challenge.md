# Day 27 终极挑战：多 API 聚合系统

## 项目名称：DataAggregator

## 背景
现代应用通常需要从多个数据源获取和整合信息。

## 目标
构建一个 API 聚合系统，从多个公开 API 获取数据并生成综合报告。

## 功能要求

### 1. 多数据源支持
- GitHub API：用户信息、热门仓库
- OpenWeatherMap API：天气数据（可用 mock）
- NewsAPI：新闻数据（可用 mock）
- 可扩展的数据源接口

### 2. 数据处理
- 数据清洗
- 格式转换
- 数据验证
- 去重处理

### 3. 数据聚合
- 合并来自不同源的数据
- 智能关联
- 统计分析

### 4. 报告生成
- Markdown 格式报告
- 包含图表（ASCII）
- 可导出 JSON

### 5. 系统特性
- 异步请求（提高效率）
- 缓存机制
- 错误处理
- 日志记录

## 输入
- GitHub 用户名
- 城市名称
- 可选的配置参数

## 输出
- Markdown 格式的综合报告
- JSON 格式的数据文件

## 限制
- 使用公开 API（无需认证或免费额度）
- 处理 API 限速
- 网络错误处理
- 超时控制
