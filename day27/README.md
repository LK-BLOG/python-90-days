# Day 27: API 实战

## 📋 学习目标

完成今天的学习后，你将能够：
- 熟练使用 requests 库
- 理解 REST API 设计
- 处理分页和认证
- 实现重试和速率限制
- 调用真实公开 API
- 封装高质量的 API 客户端

## 📚 学习内容

| 模块 | 内容 |
|------|------|
| requests 基础 | Session、响应处理、文件上传下载 |
| REST API | 设计概念、分页、认证 |
| 异常处理 | HTTPError/Timeout/ConnectionError |
| 高级特性 | 重试机制、速率限制、最佳实践 |
