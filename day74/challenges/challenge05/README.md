# Challenge 05: 文档解析管道

## Boss 挑战

前 4 个挑战分别实现了 PDF 解析器、多格式文档加载器、智能分块器和索引构建器。现在构建一个**完整的文档解析管道**。

## 目标

实现 `DocumentPipeline` 类，支持：
- 多格式文档加载（PDF/DOCX/MD/HTML/TXT）
- 智能分块（段落感知 + 重叠 + 元数据保留）
- 嵌入生成 + 向量索引构建
- 增量导入（只处理新文档）
- 批量导入进度追踪
- 错误隔离（单文档失败不影响整体）
- 导入报告

## 验收标准
- [ ] 支持 5 种文档格式
- [ ] 分块保留文档结构信息
- [ ] 增量导入只处理新文档
- [ ] 单文档失败不影响其他文档
- [ ] 导入报告包含成功/失败/跳过统计
- [ ] 通过 test_day74.py 全部测试
