# Challenge 05: 微调数据集

## Boss 挑战

前 4 个挑战分别实现了数据格式化器、数据验证器、微调配置器和微调监控器。现在构建一个**完整的微调数据集管理系统**。

## 目标

实现 `FinetuneDatasetManager` 类，支持：
- 多格式数据导入（JSON/CSV/JSONL）
- 数据清洗和预处理（去重/过滤/匿名化）
- 自动格式化为 OpenAI JSONL
- 数据验证 + 质量评分
- 训练集/验证集自动切分
- 数据集版本管理
- 微调配置 + 训练监控

## 验收标准
- [ ] 从 CSV 导入 100+ 条数据
- [ ] 去重和质量过滤正常工作
- [ ] 输出的 JSONL 格式 100% 合法
- [ ] 数据集切分比例正确
- [ ] 版本管理支持 diff
- [ ] 通过 test_day71.py 全部测试
