# Day 69 终极挑战：AI 应用网关

## 项目名称
**AIGate —— 企业级 AI 应用网关**

## 目标
构建一个统一的 AI 应用网关，封装速率限制、重试、降级、成本追踪、异步并发和流式输出等核心能力，为上层应用提供可靠的 LLM 调用基础设施。

## 功能要求
1. **速率限制器**：实现令牌桶算法，支持每秒/每分钟/每小时的限流粒度，可按 API Key 独立配置
2. **重试引擎**：指数退避 + 随机抖动，支持自定义可重试异常列表（429/500/503），最大重试次数可配
3. **降级策略**：主模型失败时自动切换备用模型（如 GPT-4 → GPT-3.5），支持配置降级链
4. **异步并发控制**：基于 asyncio.Semaphore 的并发池，支持批量请求和进度回调
5. **流式输出**：实现 SSE（Server-Sent Events）流式解析器，支持逐 token 输出和中断恢复
6. **成本追踪**：按模型/用户/API Key 维度统计 token 用量和费用，支持预算告警
7. **请求路由**：根据请求特征（模型、优先级、用户等级）路由到不同的限流/降级策略
8. **健康检查**：定期 ping 各模型端点，自动标记不可用节点
9. **统一接口**：提供 `AIGateway.chat()` / `AIGateway.stream()` / `AIGateway.batch()` 三个核心方法
10. **指标导出**：支持导出 Prometheus 格式的监控指标（QPS、延迟、错误率、成本）

## 验收标准
- [ ] 令牌桶限流在并发场景下误差 < 5%
- [ ] 重试引擎在 429 场景下正确执行退避重试
- [ ] 降级链在主模型超时时自动切换
- [ ] 异步批量请求吞吐量是串行的 3x+（模拟延迟）
- [ ] 流式输出能逐 token 打印且支持中途取消
- [ ] 成本追踪数据与实际 token 用量一致
- [ ] 完整的单元测试 + 集成测试
