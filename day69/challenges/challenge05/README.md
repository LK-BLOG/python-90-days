# Challenge 05: AI 应用架构

## Boss 挑战

前 4 个挑战分别实现了速率限制器、重试装饰器、异步调用器和成本追踪器。现在构建一个**完整的 AI 应用架构框架**。

## 目标

实现 `AIAppFramework` 类，支持：
- 统一配置管理（模型选择/参数/限流/降级策略）
- 请求管道（限流 → 重试 → 降级 → 缓存 → 调用）
- 异步并发执行 + 流式输出
- 成本控制和预算告警
- 健康检查和自动降级
- 监控指标导出

## 验收标准
- [ ] 请求经过完整的处理管道
- [ ] 超预算时拒绝请求并告警
- [ ] 主模型失败自动降级到备用模型
- [ ] 异步并发正确执行
- [ ] 健康检查能标记不可用模型
- [ ] 通过 test_day69.py 全部测试
