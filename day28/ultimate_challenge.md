# Day 28 终极挑战：并发爬取聚合系统

## 项目名称：AsyncAggregator

## 背景
需要从多个数据源并发获取数据，进行聚合分析。

## 目标
构建一个高性能的异步数据采集和聚合系统。

## 功能要求

### 1. 异步采集
- 并发请求多个 API
- 带信号量的并发控制
- 自动重试失败请求
- 超时控制

### 2. 缓存机制
- 内存缓存
- 文件缓存
- 缓存过期策略

### 3. 数据处理
- 数据清洗
- 格式转换
- 数据验证

### 4. 数据聚合
- 多源数据合并
- 统计分析
- 趋势分析

### 5. 报告生成
- Markdown 格式报告
- ASCII 图表
- 性能统计

### 6. 系统特性
- 完整的日志记录
- 错误处理
- 优雅关闭
- 配置管理

## 输入
- 数据源配置（URL 列表）
- 并发限制
- 超时设置
- 缓存配置

## 输出
- Markdown 格式的聚合报告
- JSON 格式的原始数据
- 性能统计报告

## 限制
- 使用 asyncio + aiohttp
- 支持 Python 3.9+
- 内存使用 < 100MB
- 总时间 < 30秒
