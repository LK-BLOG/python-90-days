# Day 28: asyncio 异步编程

## 📋 学习目标

完成今天的学习后，你将能够：
- 理解异步编程的概念
- 使用 async/await 语法
- 掌握 asyncio 核心 API
- 实现并发控制
- 使用异步 HTTP 库
- 对比同步 vs 异步性能

## 📚 学习内容

| 模块 | 内容 |
|------|------|
| 异步基础 | 事件循环、async/await |
| 并发控制 | create_task、gather、wait |
| 高级特性 | Semaphore、Queue、异步迭代 |
| 实战应用 | aiohttp、异步文件、并发爬虫 |
