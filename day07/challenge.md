# Day 7 挑战：CLI Todo管理器

## 挑战概述
构建一个完整的CLI交互式Todo管理器，综合运用前六天所学知识。

## 核心挑战
1. **基础功能**：实现增删改查（CRUD）操作
2. **数据持久化**：使用JSON文件存储数据
3. **用户交互**：友好的命令行界面
4. **数据验证**：输入验证和错误处理

## 具体任务

### 挑战1：基础Todo类
创建Todo类，包含以下属性：
- id: 唯一标识符
- title: 标题（必填）
- description: 描述（可选）
- priority: 优先级（高/中/低）
- tags: 标签列表
- completed: 完成状态
- created_at: 创建时间
- completed_at: 完成时间

**要求**：
- 使用函数参数设计，支持默认值
- 实现`to_dict()`和`from_dict()`方法
- 添加输入验证

### 挑战2：Todo管理器
实现TodoManager类：
- 添加Todo
- 删除Todo
- 编辑Todo
- 搜索Todo
- 过滤Todo（按优先级、状态、标签）
- 统计信息

**要求**：
- 使用闭包实现操作计数器
- 实现数据持久化（JSON文件）
- 添加异常处理

### 挑战3：用户界面
实现命令行交互界面：
- 主菜单
- 各功能界面
- 输入验证
- 友好的输出格式

**要求**：
- 使用字符串处理美化输出
- 实现输入验证
- 处理用户中断（Ctrl+C）

### 挑战4：数据统计
实现统计分析功能：
- 按优先级统计
- 按日期统计
- 完成率分析
- 标签使用频率

**要求**：
- 使用数据结构操作
- 生成统计报告
- 可选：字符图表

## 输入/输出示例

### 输入示例：
```
请选择操作 (1-7): 1
标题: 学习Python
描述: 完成Day7挑战
优先级 (高/中/低) [中]: 高
标签 (用逗号分隔): 学习,编程
```

```

📊 统计信息:

  已完成: 0
  待完成: 1
  优先级分布:
    🔴 高: 1
    🟡 中: 0
    🟢 低: 0
```
