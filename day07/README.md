# Day 7: 小型项目① — CLI Todo & 数据管理器

## 🎯 今日目标
综合运用Day 1-6所学知识，构建一个完整的CLI交互式Todo管理器。

## 📚 知识回顾
- **函数参数设计**：位置参数、关键字参数、默认值、*args/**kwargs
- **闭包与装饰器**：计数器、日志、缓存
- **字符串处理**：格式化、正则表达式、文本处理
- **数据结构操作**：列表推导式、字典操作、集合运算
- **异常处理**：try/except、自定义异常、上下文管理器

## 🛠️ 项目功能
- 增删改查Todo
- 优先级管理（高/中/低）
- 搜索和过滤
- 统计分析
- JSON文件持久化存储
