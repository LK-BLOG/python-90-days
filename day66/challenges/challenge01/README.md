# 挑战一：向量数据库基础操作

## 难度
★☆☆☆☆

## 项目名
VectorDB - 向量数据库基础操作

## 目标
实现一个简单的向量数据库类，支持向量插入、删除和相似度搜索。

## 背景
向量数据库是AI应用的核心组件。本挑战让你从零开始实现一个简化版的向量数据库，理解其核心原理。

## 功能要求
1. **向量插入**：支持插入带ID的向量和元数据
2. **向量删除**：根据ID删除向量
3. **相似度搜索**：计算查询向量与所有向量的余弦相似度
4. **Top-K检索**：返回最相似的K个向量

## 输入
- 向量：8维numpy数组
- 查询向量：8维numpy数组
- 元数据：可选的字典

## 输出
- 搜索结果：按相似度排序的向量列表

## 限制条件
- 纯Python实现，可使用numpy
- 向量维度固定为8维
- 不使用任何外部向量数据库库

## 示例
`python
db = VectorDB(dim=8)
db.insert("doc1", [0.1]*8, {"text": "Python教程"})
db.insert("doc2", [0.2]*8, {"text": "Java教程"})
results = db.search([0.1]*8, top_k=2)
# 返回按相似度排序的向量列表
`
