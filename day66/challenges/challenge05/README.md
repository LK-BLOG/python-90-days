# 挑战五：向量数据库应用系统

## 难度
★★★★★

## 项目名
VectorApp - 向量数据库应用系统

## 目标
构建一个完整的向量数据库应用，支持文档处理、向量化存储、智能检索和结果展示。

## 背景
将前几个挑战的知识整合成一个完整的应用系统，解决实际的信息检索问题。

## 功能要求
1. **文档处理**：支持导入txt/md文档，自动分块
2. **向量化存储**：将文档片段向量化并存入数据库
3. **智能检索**：支持语义搜索和关键词搜索
4. **结果处理**：去重、排序、高亮显示
5. **会话管理**：记录搜索历史和用户偏好

## 输入
- 文档文件路径
- 查询语句
- 搜索参数（top_k、过滤条件等）

## 输出
- 相关文档片段列表
- 搜索结果统计
- 搜索历史记录

## 限制条件
- 纯Python实现，可使用numpy
- 向量维度固定为8维
- 支持中文文档处理

## 示例
`python
app = VectorApp(dim=8)
app.load_document("tech.txt", chunk_size=100)
app.load_document("faq.md", chunk_size=50)
results = app.search("Python安装", top_k=5, method="semantic")
app.show_history()
`
