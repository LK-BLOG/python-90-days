# 挑战四：多集合向量检索

## 难度
★★★★☆

## 项目名
MultiVectorDB - 多集合向量检索系统

## 目标
实现一个支持多个集合的向量数据库，支持跨集合检索和集合管理。

## 背景
实际应用中通常需要管理多个不同类别的向量集合。本挑战让你实现集合管理和跨集合搜索功能。

## 功能要求
1. **集合管理**：创建、删除、列出所有集合
2. **独立索引**：每个集合有独立的向量索引
3. **跨集合搜索**：在所有或指定集合中搜索
4. **结果合并**：合并多个集合的搜索结果并排序
5. **集合统计**：显示每个集合的向量数量和元数据

## 输入
- 集合名称列表
- 向量数据（带集合标签）
- 查询向量和搜索参数

## 输出
- 搜索结果：包含集合名、向量ID、相似度分数
- 集合统计信息

## 限制条件
- 纯Python实现，可使用numpy
- 支持最多10个集合
- 每个集合最多1000个向量

## 示例
`python
mdb = MultiVectorDB(dim=8)
mdb.create_collection("tech")
mdb.create_collection("faq")
mdb.insert("tech", "doc1", [0.1]*8)
mdb.insert("faq", "doc2", [0.2]*8)
results = mdb.search([0.1]*8, collections=["tech"], top_k=3)
`
