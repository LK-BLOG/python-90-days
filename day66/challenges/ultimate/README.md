# Boss挑战：智能知识库检索系统

## 难度
★★★★★

## 项目名
VectorKB - 智能知识库检索系统

## 目标
构建一个支持多文档、多维度的向量知识库检索系统，支持文档导入、向量化存储、语义搜索和结果排序。

## 背景
企业内部有大量技术文档、FAQ、会议记录等资料，员工查找信息效率低下。需要一个智能检索系统，能快速找到最相关的文档片段。

## 功能要求
1. **文档管理**：支持导入txt/md文档，自动分块和向量化
2. **多集合管理**：按类别创建不同集合（技术文档、FAQ、会议记录等）
3. **语义搜索**：支持基于语义相似度的文档检索
4. **混合搜索**：结合关键词匹配和语义搜索
5. **结果排序**：支持按相似度、时间、来源等排序
6. **元数据过滤**：支持按标签、日期、来源等过滤结果

## 输入
- 文档文件路径或文本内容
- 查询语句
- 可选的过滤条件和排序方式

## 输出
- 按相关性排序的文档片段列表
- 每个片段的相似度分数和元数据

## 限制条件
- 纯Python实现，可使用numpy
- 向量维度固定为8维（简化版）
- 支持最多1000个文档片段

## 示例
`python
kb = VectorKB(dim=8)
kb.add_document("技术文档", "Python是解释型语言...", {"date": "2024-01-01"})
kb.add_document("FAQ", "如何安装Python？", {"date": "2024-01-15"})
results = kb.search("Python安装教程", collection="技术文档", top_k=3)
# 返回最相关的3个文档片段
`
