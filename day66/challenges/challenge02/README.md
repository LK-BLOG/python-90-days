# 挑战二：ChromaDB文档存储

## 难度
★★☆☆☆

## 项目名
ChromaDocs - ChromaDB文档存储系统

## 目标
使用ChromaDB实现一个文档存储和检索系统，支持文档导入和语义搜索。

## 背景
ChromaDB是轻量级的向量数据库，适合快速原型开发。本挑战让你掌握ChromaDB的基本操作。

## 功能要求
1. **文档存储**：将文档文本存入ChromaDB
2. **元数据管理**：为每个文档添加来源、日期等元数据
3. **语义搜索**：根据查询文本检索相关文档
4. **批量操作**：支持批量添加和查询

## 输入
- 文档文本列表
- 查询文本
- 元数据字典

## 输出
- 搜索结果：包含文档内容、ID和元数据

## 限制条件
- 使用ChromaDB库
- 文档ID自动生成或用户指定
- 支持中文文档

## 示例
`python
store = ChromaDocStore("my_collection")
store.add_documents(
    ["Python是解释型语言", "Java是编译型语言"],
    [{"source": "教程"}, {"source": "教程"}]
)
results = store.search("Python语言", n_results=2)
`
