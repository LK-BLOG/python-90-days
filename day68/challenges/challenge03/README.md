# 挑战三：重排序器

## 难度
★★★☆☆

## 项目名
Reranker - 结果重排序器

## 目标
实现一个重排序器，对初步检索结果进行精排。

## 背景
初步检索可能不够精确，重排序可以提高最终结果的质量。

## 功能要求
1. **相关性评分**：计算查询与文档的深度相关性
2. **多样性保证**：确保结果的多样性
3. **去重处理**：去除重复或高度相似的结果
4. **分数校准**：对不同模型的分数进行校准

## 输入
- 查询文本
- 初步检索结果列表
- 重排序参数

## 输出
- 重排序后的结果列表
- 每个结果的新分数

## 限制条件
- 纯Python实现
- 不依赖外部重排序模型
- 支持中文文档

## 示例
`python
reranker = Reranker()
results = [("doc1", 0.8), ("doc2", 0.7), ("doc3", 0.6)]
reranked = reranker.rerank("Python性能优化", results, top_k=2)
`

## 验收标准
- [ ] 相关性评分逻辑正确
- [ ] 多样性保证有效
- [ ] 去重处理正常
- [ ] 分数校准功能完整
- [ ] 代码有中文注释
