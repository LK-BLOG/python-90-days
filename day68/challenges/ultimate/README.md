# Boss挑战：高级RAG系统

## 难度
★★★★★

## 项目名
AdvancedRAG - 高级RAG系统

## 目标
构建一个集成Query Rewriting、HyDE、Reranking和评估的高级RAG系统。

## 背景
基础RAG系统存在检索质量不稳定、答案缺乏依据等问题。本挑战让你构建一个生产级的RAG系统。

## 功能要求
1. **查询优化**：自动改写和扩展用户查询
2. **HyDE检索**：使用假设答案提高检索效果
3. **智能路由**：根据查询类型选择最佳检索策略
4. **重排序**：对初步检索结果进行精排
5. **自评估**：自动评估答案质量和可信度
6. **反馈循环**：根据评估结果优化系统

## 输入
- 知识库文档
- 用户查询
- 可选的检索策略配置

## 输出
- 优化后的答案
- 检索质量评估报告
- 系统性能统计

## 限制条件
- 纯Python实现
- 不依赖外部LLM（可模拟）
- 支持中文查询

## 示例
`python
rag = AdvancedRAG()
rag.load_knowledge_base(docs)
answer = rag.query("如何优化Python性能？")
report = rag.evaluate(test_set)
# 返回优化后的答案和评估报告
`
